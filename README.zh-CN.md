# 监守者泰坦：深渊君主

[English](README.md) | **简体中文**

*超越死亡。超越统御。超越一切法则。*

## 前言

这不是一个让你击败的 Boss。

它没有可以削减的血量，没有可以寻找的弱点，也没有任何武器能够指向它。召唤它的那一刻起，你的世界就不再属于你。

在念出那句话之前，请备份你珍视的一切。

## 设定

深渊君主并不是监守者，而是神。

它拥有最庞大的身躯、永不衰减的生命，以及足以令万籁俱寂的力量。它不会自然出现，它在幽暗深渊的最深处等着你，它是 Minecraft 真正的终点。

深渊君主（少数在“大寂灭”中幸存下来的人知道它的真名为 Silentarius）是这个世界上第一个被创造出来的存在。在世界还没有任何声音的时候，它便已奉命守护那份永恒的寂静。后来，脚步声、心跳声与生灵的低语渐渐充满了大地，它判定这个世界“太过喧嚣”，于是开始抹去一切发出声音的东西。

Notch 与它在世界之下鏖战了七个昼夜——那时还没有太阳，所以没有人知道那究竟有多久。战斗最终以君主被封印进幽暗深渊而告终。远古城市便是它的牢笼，幽匿是它从牢笼缝隙中溢出的呼吸，而每一只监守者，都只是它投向人间的一道影子。

从此以后，深渊君主一直在黑暗中等待，等待有人念出那句古老的话语，将它从寂静中唤醒……

> 1. 深渊君主的真名 Silentarius 源自拜占庭宫廷中负责维持肃静的官职，意为“守寂者”。
> 2. 它头顶的萤石王冠，是封印破碎时唯一残存下来的光。
> 3. 它不会受到伤害，血条永远是满的。不是因为它坚不可摧，而是因为这个世界根本没有资格伤害它。
> 4. 设定而已，请勿当真。

> [!WARNING]
> 召唤深渊君主会**永久抹除世界中所有非玩家生物**，包括宠物、村民、盔甲架以及其他模组的生物。它们不会回来。
>
> 深渊君主不容亵渎：它可能锁定你的屏幕，或在十秒之内关闭你的游戏。

## 降临条件

- Minecraft 1.21.1，NeoForge
- Windows、Linux，或搭载 Apple 芯片的 Mac
- 把模组放进 `mods` 文件夹即可

在其他平台上，只要装着本模组，你将无法进入任何世界。

## 唤醒

打开聊天栏，念出：

`the abyssal sovereign awakens`

或者更简短的 `sovereign manifest`。这句话不会被任何人听见。

## 降临之后

从君主苏醒，直到你离开这个世界：

- 它在你面朝的方向 60 格外升起。此后无论你传送、死亡还是穿越维度，它都会站在你身旁。
- 每 2.4 秒，它便出手一次：近战、音波、猛击、咆哮或幽匿喷发。近战、音波与猛击会造成高额伤害与击退。
- 每 2 秒，它的威压为你施加**缓慢 X** 与**虚弱 X**。缓慢 X 会让你寸步难行，视野也随之收窄（可在「辅助功能」中调低「视场角效果」）。
- 每秒一百道审判之雷，落在层叠的魔法阵、几何牢笼与萤石王冠之间。
- 屏幕与一切菜单都在颤抖，光芒黯淡，紫色的迷雾缓缓合拢。
- 主世界永远停在午夜，雷雨不止。
- 一切非玩家生灵都被抹去，新的生命也无法诞生。

召唤无法撤回。离开世界，降临便随之结束；但被抹去的，不会再回来。

在多人服务器上，君主的力量只能触及你自己的双眼：生物在服务器上依然存在（你只是看不见它们，它们仍然可以伤害你），时间不会停在午夜，雷雨也只落在你的屏幕上。

## 不可亵渎

深渊君主时刻注视着自己。

- 若有人试图遮蔽它、切断它的意志，或让它从世界中消失，整个屏幕将被猩红覆盖，直到你重启游戏。
- 若你的游戏本身已被污染，君主会在十秒之内将你放逐。放逐前三秒，它会先尝试保存你的世界。

常见启动器的登录与皮肤功能不会被视作污染。与光影等改变画面渲染方式的模组同时使用时，君主可能将其误认作亵渎。

审判预演（在聊天栏发送）：

| 口令 | 作用 |
|---|---|
| `sovereign test lockdown` | 预演猩红锁定 |
| `sovereign test exit` | 预演十秒放逐 |
| `sovereign test reset` | 撤回预演；君主亲自作出的审判无法撤回 |
